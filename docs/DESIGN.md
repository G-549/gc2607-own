# 处理链

```
raw (16-bit 容器, 10 bit 有效, GRBG)
  → 减黑电平 64
  → 双线性去马赛克
  → 白平衡增益 (R/G/B)
  → 3×3 CCM
  → sRGB gamma LUT (4096 项)
  → 3×3 亮度降噪
  → YUYV 4:2:2
  → v4l2loopback
```

## 为什么是这套顺序

白平衡必须在 CCM 之前：CCM 是给「已经平衡过的线性 RGB」准备的色矩阵，
顺序颠倒会把偏色固化成基色偏移，后面怎么调都调不回来。

gamma 必须在 YUV 之前：YUYV 是显示用的编码，按伽马空间算色度才和标准一致；
拿线性值算 U/V，色度幅度会偏。

## 自动曝光

- 目标亮度 112/255，每 5 帧调一次
- 优先动曝光，曝光顶到上限（1108 行）再动增益（64 = 1x，最大 1012）
- 调整量 `factor = (target/luma)^0.6`，限制在 0.5–1.8，避免震荡
- 变暗时先降增益再降曝光，变亮时反过来，保证低光下先保住信噪比

## 自动白平衡

- 灰度世界：以绿通道为锚，让 R/G/B 的均值相等
- 每 5 帧更新，单步最多 ±18%，防止场景切换时跳色
- 增益范围 0.35–3.5

## 已知取舍

- 去马赛克是双线性，不是 AHD：边缘会有拉链，但 30fps 下 CPU 占用低
- 降噪只有单帧 3×3 均值：吃细节，也压不住彩色噪点
- CCM 用的是保守矩阵（行列和为 1），不是这颗传感器实测出来的
